# Shift & Leave Tracker

Open the tracker: https://raptor2302.github.io/shift-tracker/

A 4-day M / N / OFF / OFF shift rota with leave tracking (OL, OVL, OIL, HL, FCL, MC and more) and Singapore public holidays.
Everything you enter is saved only in your own browser. Use Export JSON to back it up or move it to another device.
